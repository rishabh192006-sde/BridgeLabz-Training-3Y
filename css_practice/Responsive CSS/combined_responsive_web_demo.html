Responsive Design

Responsive design allows a webpage to adapt its layout, images and text to different screen sizes.

Flexbox, Grid and media queries are commonly used to create responsive websites.

Cheat Sheet

Grid Creates responsive layouts.
Flexbox Aligns elements easily.
Media Query Changes styles at breakpoints.
