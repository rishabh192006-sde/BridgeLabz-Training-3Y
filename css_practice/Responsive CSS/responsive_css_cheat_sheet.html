Responsive CSS Cheat Sheet

Important concepts for responsive websites

Filters

CSS filters modify the appearance of images.

filter: grayscale(100%);

Media Queries

Media queries apply styles according to screen size.

@media (max-width: 700px)

Responsive Design

Responsive design allows websites to adapt to devices.

width: 100%;

Typography

Relative units help text scale across screen sizes.

font-size: clamp(1rem, 2vw, 2rem);
